# Passafe Password Manager

**Passafe** is a secure Android password management application designed to safeguard user credentials using advanced encryption and biometric authentication. It allows users to access their passwords **offline** for enhanced privacy and convenience.

---

## 🚀 Features

- 🔒 Secure password storage with encryption
- 🛡️ Biometric authentication (fingerprint, face unlock)
- 📴 Offline access to all stored credentials
- 📱 Intuitive, mobile-friendly UX/UI
- 🛡️ Efficient encryption preventing unauthorized access

---

## 🛠️ Technologies Used

- **Java** (Android development)  
- **SQLite** database for encrypted local storage  
- Android **biometric authentication APIs**  
- Encryption libraries for data security  

---

## 🚧 Getting Started

1. Clone or download the repository to your local machine.  
2. Open the project in **Android Studio**.  
3. Build and run the app on an Android device or emulator.  
4. Use biometric authentication or app credentials to login securely.  
5. Add, view, edit, and delete stored passwords with encryption.  

---

## 💡 Benefits

Passafe offers enhanced password security with biometric protection and offline access, simplifying secure credential management without risking internet exposure.
